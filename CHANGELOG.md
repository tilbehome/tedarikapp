## [Yayınlanmadı]
### Eklendi
- Faz 0: Proje belge seti v1.0 (docs/00–09), CLAUDE.md geliştirme anayasası, repo iskeleti.
- Faz 0 (K18): API sözleşmesi (docs/10) — uç bazlı istek/yanıt, hata zarfı, sayfalama sabitlendi.
- Faz 1 çekirdeği: Slim iskeleti, config/log katmanı, migration altyapısı, auth çekirdeği tabloları (İE#3). PHP 8.4'e geçildi (K21).
- Faz 1 kimlik doğrulama (İE#4): docs/10 §2'deki 7 auth ucu (login / totp / recovery / logout / me / sessions listesi ve iptali); Argon2id şifre hash'i, şifreli TOTP secret'ı ve tek kullanımlık kurtarma kodları; oturum katmanı (HttpOnly + SameSite=Lax çerez, boşta kalma aşımı, girişte kimlik tazeleme); Auth / Csrf / LoginRateLimit middleware'leri (artan bekleme + IP kilidi, `meta.retry_after_seconds`); selector+validator desenli "beni hatırla" token'ı ve çalıntı token tespitinde toplu iptal; giriş olaylarının activity_log'a yazılması; `bin/user-create.php` geliştirme aracı (terminalde QR + kurtarma kodları). Paketler: robthree/twofactorauth, bacon/bacon-qr-code (K19).
- Faz 1 kurulum sihirbazı (İE#5): `storage/setup.lock` yoksa açılan, bittiğinde kalıcı kilitlenen tek seferlik kurulum akışı — gereksinim denetimi (PHP ≥ 8.4, zorunlu eklentiler, `storage/` + `public/media/` yazılabilirliği, HTTPS uyarısı; eksikler isim isim ve çözüm önerisiyle), veritabanı bağlantı testi (`SELECT VERSION()`, utf8mb4 zorunlu), `.env` üretimi (APP_KEY ve eklenti token tuzu kriptografik, dosya izni 0600, atomik yazım), migration koşumu (ad + süre), yönetici hesabı + TOTP QR (Bacon SVG) doğrulaması ve **yalnızca bir kez gösterilen** kurtarma kodları. Adım sırası sunucuda zorlanır; sihirbazın kendi oturumu ve CSRF token'ı vardır. Güncelleme yolu: `GET /api/system/status` + `POST /api/system/migrate` (auth + CSRF).
- `JsonRequest` middleware: gövdeli yazma isteklerinde JSON zorunlu, değilse 415 `UNSUPPORTED_MEDIA_TYPE` (docs/10 §1).

- Faz 1C veri katmanı (İE#6): `lists`, `products`, `product_images`, `product_status_history`, `exports` tabloları (K23: 1 dosya = 1 DDL; enum'lar İngilizce — K22). **MoneyService** para hesaplarının tek merkezi (K29): bcmath HALF_UP, ara hesap scale 6, "önce yuvarla sonra topla" (K24). **StateMachine** ürün ve liste geçiş matrisleri (tek adım geri, `received`'dan iptal yok, `completed` tüm ürünlerin kapanmasını ister). API: liste CRUD + kopyalama + görünürlük + soft delete; ürün CRUD + toplu işlem + sıralama + tekrar uyarısı; çöp kutusu listesi/geri alma/kalıcı silme. Kur listeye oluşturmada kopyalanır, `sent` ile kilitlenir ve bir daha değişmez (K4). `bin/purge-trash.php` saklama süresi dolan kayıtları temizler (cron adayı).

- Faz 1 (İE#7 · K33 sunucu uyumu): üretimde uygulama diske yazamadığı için (PHP `nobody`, DSO) **dosyasızlaştırma** — loglar `app_logs` tablosuna (`LOG_DRIVER=db|file`), kurulum kilidi `settings` tablosuna taşındı (eski dosya kilidi okunmaya devam eder); sihirbaz `.env`'i yazamazsa içeriği gösterip elle kaydedileni APP_KEY eşleşmesiyle doğruluyor. **MediaService** çift modlu: `public/media` yazılabiliyorsa indir → GD ile yeniden kodla → kriptografik rastgele ad, değilse `hotlink` (orijinal URL saklanır). SSRF kapısı: yalnız HTTPS, tam sonek host eşleşmesi, iç ağ IP reddi, yönlendirme hedefinin yeniden denetimi, MIME allowlist (SVG yasak), magic-byte doğrulaması. `public/media/.htaccess` ve `robots.txt` repo ile geliyor.
- Faz 1D React paneli (İE#8): `frontend/` altında React 19 + TypeScript + Vite + Tailwind 4 + Zustand + React Router 7 + Lucide paneli; ekranlar docs/09 envanterine göre E1 Giriş (şifre→TOTP→kurtarma), E2 Ana Ekran, E3 Listeler (Aktif/Pasif/Arşiv sekmeleri, dönem başlıkları, ilerleme çubuğu), E4 Liste Detayı (telefonda kart / masaüstünde tablo, sıralama, toplu durum işlemi, backend'den gelen TOPLAM satırı), E5 Ürün Ekle/Düzenle (tekrar uyarısı akışı, görsel URL → MediaService), E7 Çöp Kutusu, E8 Ayarlar + Kategoriler, E9 Aktivite. API istemcisi zarfı çözer, CSRF başlığını taşır, 401'de girişe döner; hata kodları Türkçe sözlükten okunur. Para alanları `string` gelir, `string` gösterilir — panelde tek satır para aritmetiği yoktur (K14/K29). Export ve Paylaşım butonları görünür ama "Faz 2" rozetiyle pasiftir; Gelen Kutusu menüde "yakında" olarak durur.
- Faz 1D (İE#8 · panelin gerektirdiği uçlar): `GET /api/activity` (docs/10 §7'de tanımlıydı, gerçeklendi — E9'un kaynağı, `entity_type`/`entity_id` süzgeci + sayfalama) ve `GET /api/system/state-machine` (izinli durum geçişlerinin haritası; panel geçersiz geçişi kullanıcıya hiç sunmaz, kural yine backend'de zorlanır). Ürün ekleme/düzenlemede verilen görsel adresi artık MediaService'ten geçer (docs/10 §4).
- Faz 1 (İE#7): ayarlar ve kategori uçları — `GET /api/settings`, `PUT /api/settings/rates` (→ `rate_history`), `GET /api/settings/rates/history`, `GET/POST/PATCH/DELETE /api/categories` (kullanımdaki kategori silinemez). `products.raw_attributes`, `country_of_origin`, `country_of_dispatch` kolonları (GTİP hazırlığı — M23 değerlendirmesi §6).

### Güvenlik
- CSP `img-src` artık sabit `'self' data:` değil, `MEDIA_ALLOWED_HOSTS` ayarından üretiliyor (yalnız `https://host` ve `https://*.host`). Eski sabit politika K33 hotlink modundaki görsellerin tamamını tarayıcıda blokluyordu; indirme beyaz listesiyle görüntüleme politikası artık tek kaynaktan besleniyor.
- `main_image` alanı diğer URL alanlarıyla aynı doğrulamadan geçiyor (yalnız https, uzunluk, biçim) ve ardından MediaService'in beyaz liste/SSRF kapısına giriyor; arşiv modunda indirilip yeniden kodlanıyor, hotlink modunda doğrulanmış HTTPS adresi saklanıyor. Sistemin kendi ürettiği yerel yol (`/media/…`) yeniden indirilmiyor.
